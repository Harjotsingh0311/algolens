# Experimental Chunking Outputs

Generated by `tools/build_chunks.py`.

- `parents.jsonl`: larger hierarchical context chunks.
- `children.jsonl`: smaller retrieval chunks with parent IDs.
- `report.json`: source verification, scope rules, chunk counts, and word counts.

These are experimental artifacts, not approved canonical lecture content.

The typed-note extraction retains some damaged equations and diagram fragments.
The caption track is auto-generated and has not been fully spot-checked.
Do not treat citation metadata or successful hash checks as proof of content
accuracy. See `docs/chunking-pipeline.md` before using these files downstream.
