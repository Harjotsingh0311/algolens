## How AlgoLens handles source material

The project distinguishes the source document, automatically extracted text, and selectively reviewed formula excerpts. Automated extraction can introduce errors; those outputs must not be presented as fully verified lecture material.

Where source-derived material is redistributed, preserve attribution to MIT OpenCourseWare, identify modifications, comply with the applicable noncommercial restriction, and follow the share-alike requirement. Check the source asset for any special notices or third-party exceptions before redistributing it.

This note records project practice; it is not legal advice. It does not claim that MIT endorses AlgoLens.

## Application code versus source-derived content

Independently written application code and source-derived educational material may have different licensing requirements. Do not assume that a license for the application automatically replaces the terms attached to the underlying educational content.
